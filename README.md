# GutR
O GutR é uma ferramenta desenvolvida em R para automatizar a análise quantitativa da dieta da herpetofauna. O script organiza os dados de conteúdo estomacal, calcula métricas de importância dos itens alimentares e índices de nicho, como Levins e Pianka, e gera automaticamente tabelas e gráficos dos resultados.
